# Project

FastWarp is developed in the open on [GitHub](https://github.com/WyssCenter/fastwarp). It is
maintained by Richard Köhler ([@richardkoehler](https://github.com/richardkoehler)) and Jan
Philipp Payonk ([@JPPayonk](https://github.com/JPPayonk)). Support is given on a best-effort
basis through [GitHub issues](https://github.com/WyssCenter/fastwarp/issues).
