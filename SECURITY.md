# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Do not open a public issue. Use GitHub private vulnerability reporting: on the
[repository page](https://github.com/WyssCenter/fastwarp), open the *Security* tab and choose
*Report a vulnerability*. Describe the problem, the affected version and how to reproduce it.
