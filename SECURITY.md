# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Do not open a public issue. Use GitHub private vulnerability reporting: on the
[repository page](https://github.com/WyssCenter/fastwarp), open the *Security* tab and choose
*Report a vulnerability*, or go directly to the
[new advisory form](https://github.com/WyssCenter/fastwarp/security/advisories/new). Describe the
problem, the affected version and how to reproduce it.

The maintainers, Richard Köhler ([@richardkoehler](https://github.com/richardkoehler)) and Jan
Philipp Payonk ([@JPPayonk](https://github.com/JPPayonk)), handle reports on a best-effort
basis. There is no guaranteed response time.
